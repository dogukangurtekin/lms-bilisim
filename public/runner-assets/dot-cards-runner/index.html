Nasıl oynanır?

Amaç: küçük noktayı turuncu hedefe ulaştırmak. Noktayı doğrudan sen yönetmezsin; kartlar yönetir. Her kartın üzerinde küçük bir program yazar. Kartı seçince nokta o programı çalıştırır.

  • Canlar: Her bölümde 2 canın var (♥ ♥). Yanlış hamle (duvara çarpan ya da çukura düşüren kart, hedefe götürmeyen kart) bir can götürür; ikisi de bitince bölüm baştan başlar. Hiç can kaybetmeden bitirirsen 3 yıldız alırsın.
  • Kart Dizisi bölümlerinde kartları doğru sırayla seç. Bir kart noktayı duvara çarpıtırsa ya da çukura düşürürse nokta önceki yerine döner ve kart geri gelir.
  • Doğru Kartı Bul bölümlerinde yalnızca tek kart hedefe götürür. Kodları okuyarak tahmin et.
  • Serbest Gezinti bölümlerinde ok tuşlarıyla (ya da düğmelerle) noktayı sen yürütürsün.

Komutlar

  • sağa(3) sola(2) yukarı(1) aşağı(4) — o yöne belirtilen kare kadar yürür.
  • ileri(2) — noktanın baktığı yönde yürür. dön_sağ() / dön_sol() — baktığı yönü çevirir.
  • tekrarla (3) { … } — içindekileri 3 kez yapar.
  • eğer (önüm_boş) { … } değilse { … } — koşul doğruysa birincisini, değilse ikincisini yapar.
  • iken (önüm_güvenli) { … } — koşul doğru olduğu sürece tekrarlar.

Koşullar

  • önüm_boş: önümde duvar yok · önüm_güvenli: önümde duvar da çukur da yok
  • sağım_boş / solum_boş: sağımda / solumda duvar yok
